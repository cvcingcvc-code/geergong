# GORGON DEMO MVP — PHASE 1 AUDIT

> 审计对象：`http://localhost:8000/ui_kits/app/`（恢复基线 `recovery-v0` 的原始状态）
> 审计方式：**真实浏览器**（headless Microsoft Edge / Chromium via CDP），实际操作点击、输入、刷新，
> 并读取 `console`。不是只读代码判断。
> 审计日期：2026-09-15 · 分支 `feature/demo-mvp`

## 0. 环境与基线

| 项 | 值 |
|---|---|
| 静态服务 | `python -m http.server 8000 --bind 127.0.0.1`（项目根目录） |
| 浏览器 | Microsoft Edge（Chromium）headless |

## 1. 逐屏审计结果

### 发现（Discover）

| 交互 | 实际行为 | 结论 |
|---|---|---|
| 活动卡片列表 | 渲染 6 张 `ActivityCard`，含分类/时间/地点/距离/标签/价格 | ✅ 真实 |
| 分类筛选（全部/运动/音乐/艺术/美食/户外/学习） | 点击分类 → 列表按 `category` 过滤（点「运动」得到 0 张，因样例数据无运动类） | ✅ 真实生效 |
| 「本周末 / 下周末 / 全部」分段控件 | 点击后列表**完全不变** | ⚠️ 纯 UI（`when` state 未参与筛选） |
| 「筛选」按钮 | 点击后 DOM 无任何变化，无弹层 | ⚠️ 纯 UI |
| 顶部搜索框 | 输入 `AI` 后列表**不变**（feed 不过滤） | ⚠️ 纯 UI（未接线） |
| 顶部横幅「就在你附近 **38** 场」 | 硬编码；实际仅 6 条数据 | ❌ 假数据（数字对不上） |
| 点卡片进入详情 | 详情页正常打开 | ✅ 真实 |

### 活动详情（Activity Detail）

| 项 | 实际行为 | 结论 |
|---|---|---|
| 标题/时间/地点/票价/分类/标签 | 全部渲染 | ✅ 真实 |
| 主办方 `host` + 认证徽章 + 来源 `SourceTag` | 全部渲染 | ✅ 真实 |
| 描述 / 参加须知 / 到达方式（`RoutePlanner`） | 全部渲染 | ✅ 真实 |
| **报名入口** | 无独立「报名 / 购票」按钮（仅靠 `contact` 文案） | ⚠️ 缺失 |

| 「同步到我的周末」 | 点击 → 变为「已同步到我的周末」 | ✅ 真实（但仅内存） |

### 我的周末（My Weekend）

| 场景 | 实际行为 | 结论 |
|---|---|---|
| 同步 2 个活动后 | 正确出现 2 场，按周六/周日分组，统计条正确 | ✅ 真实 |
| **刷新浏览器** | **活动全部消失**，回到「周末还空着」empty state；localStorage 为空 | ❌ 无持久化 |
| 移除活动 | 通过卡片上的「已同步」按钮再次点击可取消 | ✅ 可行（内存内） |
| 底部 tab 角标 | 显示 `Object.keys(synced)` 数量（含初始 `a2/a5` 等**不存在**的 id），与实际场次不一致 | ⚠️ 角标计数口径错误 |
| 初始同步态 | 硬编码 `{a2:true, a5:true}`，但活动 id 是 `r1…r6`，**初始就带着 2 个幽灵条目** | ❌ 假数据残留 |

### 搜索（Search）

| 查询 | 结果 | 结论 |
|---|---|---|
| `hackathon` | 找到 0 场 | ❌ |
| `AI` | 找到 0 场 | ❌ |
| `徐汇`（区域） | 找到 0 场 | ❌ |
| `免费` | 找到 2 场（命中 tag） | ✅（窄） |
| 无匹配 `zzzz` | 找到 0 场，**无 empty state**（只有空白列表） | ⚠️ 缺 empty state |

> 根因：`results = activities.filter(a => a.title.includes(q) || a.tags.some(t => t.includes(q)))`
> —— 只搜 `title` + `tags`，**大小写敏感**，未覆盖 `desc / category / location / district`。

### 地图（Map）

| 项 | 实际行为 | 结论 |
|---|---|---|

## 2. 汇总：真实 vs 纯 UI

**真实可用的交互**
1. 分类筛选（Discover）
2. 卡片 → 详情跳转
3. 详情页全部内容渲染（含信任层、路线规划、报错反馈）
4. 「同步到我的周末」开关（内存态）
5. 我的周末按日分组 + 统计
6. 搜索（仅 title / tags，大小写敏感）
7. 地图 pin 选择 + 底部卡片 → 详情
8. Admin 通过 / 退回 / 拒绝（内存态）

**纯 UI（无行为）**
1. Discover 顶部搜索框
2. 「本周末 / 下周末 / 全部」分段控件
3. 「筛选」按钮
4. 详情页 收藏❤️ / 分享 / 关注
5. 空结果时的 empty state

**假数据 / 硬编码**
1. 横幅「就在你附近 38 场」
2. 地图图例「附近 6 场」
3. 初始同步态 `{a2:true, a5:true}`（幽灵条目）

**刷新即丢失**
1. 我的周末同步
2. Admin 审核决策

**Console**
- 无 blocker error（唯一 error 为 `/favicon.ico` 404，无害）
- 警告：Tracking Prevention（lucide CDN）、React DevTools 提示、Babel in-browser 提示（均无害）
