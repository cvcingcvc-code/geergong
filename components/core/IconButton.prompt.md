Square icon-only button — toolbars, card actions (heart, share), nav controls.

```jsx
<IconButton label="收藏" variant="soft" active><i data-lucide="heart" /></IconButton>
```

Variants: `ghost` `soft` `outline` `solid`. Sizes: `sm` `md` `lg`. Use `active` for toggled state (turns indigo). Always pass a `label` for accessibility.
