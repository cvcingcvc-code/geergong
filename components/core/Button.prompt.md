Primary call-to-action button — Chinese-first label, used for 去发现 / 立即同步 and other actions.

```jsx
<Button variant="primary" size="md">去发现</Button>
<Button variant="mint" leadingIcon={<i data-lucide="check" />}>已同步</Button>
```

Variants: `primary` (indigo, brand glow), `secondary` (white + border), `ghost` (text-only indigo), `mint` (reward/synced green), `inverse` (ink). Sizes: `sm` `md` `lg`. Props: `block`, `disabled`, `leadingIcon`, `trailingIcon`.
