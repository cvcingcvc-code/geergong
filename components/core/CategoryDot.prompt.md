Category color dot — the primary way activity types are signalled across Gorgon. Six categories, each a `--cat-*` hue.

```jsx
<CategoryDot category="music" showLabel />
```

Categories: `sport` 运动 · `music` 音乐 · `art` 艺术 · `food` 美食 · `outdoor` 户外 · `study` 学习. Export `CATEGORIES` maps key → {color,label}.
